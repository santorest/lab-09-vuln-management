# Lab 09 — Vulnerability management workflow

Scan a small fleet of deliberately outdated lab hosts with Greenbone, prioritize with CVSS + EPSS + CISA KEV + asset
criticality under a written policy, track remediation with SLA due dates, remediate, rescan and report. Everything
runs in GitHub Actions against containers; no real network is scanned.

Documentation follows in `docs/` and the write-ups.
